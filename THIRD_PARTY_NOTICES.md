# Third-Party Data

This project includes or derives generated assets from the following data sources:

- [IANA Time Zone Database](https://www.iana.org/time-zones), version `2026c`. The tz database code and data are in the public domain unless otherwise specified by its upstream license.
- [Unicode CLDR](https://cldr.unicode.org/), version `48.2.0`, under the Unicode License v3 (`Unicode-3.0`). The complete license text is stored at [`data/cldr/LICENSE`](data/cldr/LICENSE).
- [ICU time zone data](https://github.com/unicode-org/icu-data), tzdata `2026c` build, under the Unicode License v3 (`Unicode-3.0`). Stored at [`data/icu-tz/`](data/icu-tz/) and used only at generation time to pin the tz database version; it is not shipped with the wallpaper.
- [Natural Earth](https://www.naturalearthdata.com/), 1:110m land data. Natural Earth vector and raster map data are in the public domain.
